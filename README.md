# Лабораторная работа №3 — Вариант 06 «Аэропорт»

**Цель:** Исследование и восстановление речевых записей с акустическими помехами.

Проект представляет собой модульный конвейер на Python для обработки аудио: от анализа зашумленного сигнала до фильтрации и оценки результата (SNR/ΔSNR). Датасет: открытый корпус NOIZEUS (шум аэропорта).

## Требования и установка

1. **ОС:** Windows (инструкции написаны для PowerShell).
2. **Python:** версия 3.11 или выше.
3. **Библиотеки:** `numpy`, `scipy`, `matplotlib`, `pandas`, `soundfile` (полный список см. в `requirements.txt`).

### Установка виртуального окружения (PowerShell):
**Вариант 1: Если PowerShell разрешает выполнение скриптов (стандартный случай):**
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

**Вариант 2: Если PowerShell блокирует выполнение скриптов (ошибка UnauthorizedAccess):**
```powershell
py -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

## Загрузка данных

Датасет не хранится в репозитории. Для загрузки используется скрипт указанный ниже.

```powershell
py tools/download_dataset.py --out dataset
```

## Запуск

Основная точка входа — файл `main.py`. Конвейер состоит из 6 этапов.

```powershell
# Посмотреть справку по всем доступным аргументам
py main.py --help

# Запустить весь пайплайн (все 6 этапов)
py main.py

# Запустить только конкретные этапы (например, графики и оценку)
py main.py --stages 2,5

# Переопределить выбранные для анализа фразы
py main.py --selected sp01,sp15,sp20
```

## Важное замечание по отчету

Скрипт автоматически генерирует черновик отчета (`results/report.md` и `results/report.html`) с числовыми данными и заглушками. 

**Внимание:** Итоговый вывод и анализ в таблице выполнялись вручную. Чтобы повторный запуск скрипта не затёр ручные правки, итоговые версии отчета сохранены в виде дубликатов:
* **`results/report_saved.md`** — итоговый Markdown-отчет.
* **`results/report_saved.html`** — итоговый HTML-отчет.

При проверке просим ориентироваться на файлы `report_saved.*`.
